# Hotfix: quality report elevation/job lookup

**Stopgap, not a release.** This patches three files in the running `app` container's writable layer; it is wiped on the
next image pull. Written against the last commit (`024bb89`), which is assumed to be what prod is running.
Run from the directory on the production box where the right compose file is the default (no `-f`).

**What it changes**
- Auto-match on upload: if no candidate work order is found in the usual window (open, or completed in the last 45 days),
  it retries with completed work orders from the last 365 days.
- Manual elevation picker: lists elevations on every work order, including completed and archived ones (labelled
  "– completed" / "– archived"), and is now a type-to-search box (matches tag, work order, job name).
- Job picker: includes completed jobs.

Files: `app/Services/ElevationMatcherService.php`, `app/Http/Controllers/Api/QualityReportController.php`,
`resources/views/fabrication/quality.blade.php`.
